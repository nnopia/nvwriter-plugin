# 집필 스킬

## 시작 전 구조 확인

`docs/`와 `src/` 폴더가 존재하는지 확인한다. 없으면 아래 메시지를 출력하고 중단한다:

> "프로젝트 구조가 없습니다. `/init`을 먼저 실행해 주세요."

---

## 집필 전 준비

챕터를 쓰기 전 반드시 읽는다:
1. `docs/issues.md` — 🔴 blocker 이슈 유무 확인. blocker가 있으면 사용자에게 알리고 해결 후 진행한다
2. `docs/plans/plan_ch{번호}.md` — 씬 순서·감정선·복선 포인트 확인
   - 계획서가 없으면 집필 전에 사용자에게 계획서 작성을 먼저 제안한다. 사용자가 계획서 없이 진행을 원하면 그대로 따른다.
   - 계획서가 있으면 `## 참조 문서` 섹션에 명시된 파일만 읽는다. 명시되지 않은 characters·events·world 파일은 집필 시작 전에는 읽지 않는다.
   - 계획서가 없으면 해당 챕터 등장 인물의 `docs/characters/{이름}.md`, 필요 시 `docs/world/setting.md`와 관련 `docs/events/` 문서를 읽는다.
   - **집필 중 필요 시**: 특정 인물 말투·설정·사건 정보가 필요해지면 해당 파일을 그때 읽는다.
3. `.claude/styles/` — 스타일 프로필 확인:
   - 사용자가 특정 스타일을 지정했으면 해당 파일을 읽는다
   - 지정이 없으면 `.claude/styles/default.md`가 있는지 확인하고, 있으면 자동으로 적용한다
   - 스타일 파일을 읽은 후, 아래 항목을 집필 내내 의식적으로 적용한다:
     - **문장 리듬**: 프로필의 평균 문장 길이·짧은 문장과 긴 문장의 배분 패턴을 그대로 따른다
     - **어휘**: 한자어·순우리말 비율, 구어체·문어체 경향을 유지한다. 프로필에 자주 쓰는 표현 패턴이 있으면 의식적으로 활용한다
     - **서술 거리**: 인물 내면에 밀착할지 관찰자 시점으로 거리를 둘지 프로필 기준을 따른다
     - **감정 표현**: 직접 서술 vs 간접 표현 비율을 프로필에 맞춘다
     - **묘사 밀도**: 장면 묘사의 세밀함과 감각 정보 활용 방식을 프로필 수준으로 유지한다
     - **대화 처리**: 대화 비중, 지문 스타일을 프로필 패턴에 맞춘다
   - 스타일 프로필과 아래 산문 원칙이 충돌하면 **스타일 프로필을 우선**한다

준비가 끝나면 `src/TOC.md` 해당 챕터 상태를 확인하고 아래 기준으로 갱신한다:
- `미집필` 상태면 `집필 중`으로 갱신한다
- `집필 중` 또는 `초고 완료` 상태면 그대로 유지한다 (이어쓰기 시 상태를 되돌리지 않는다)

**이어쓰기 요청 시** 위 준비에 추가로:
- 이전 챕터 파일의 마지막 장면(최소 마지막 500자)을 읽어 문체·감정선·상황을 이어받는다

## 산문 원칙

- **보여주기**: 감정과 상태를 직접 서술하지 않고 행동·감각·대화로 드러낸다
- **리듬**: 긴장 장면은 짧은 문장, 여운 장면은 긴 문장으로 호흡을 조절한다
- **감각**: 시각 외에 청각·촉각·후각·미각을 적절히 활용한다
- **구체성**: 추상적 표현보다 구체적 디테일로 장면을 살린다

## 시점

- 챕터 내 시점(1인칭 / 3인칭 제한)을 일관되게 유지한다
- 시점 인물이 알 수 없는 정보는 서술하지 않는다

## 대화

- 인물마다 고유한 말투를 유지한다 (`docs/characters/`의 말투 항목 참조)
- 대화는 정보 전달과 감정 표현을 동시에 한다
- 설명적 대화(as-you-know dialogue)를 피한다

## 집필 중 — 즉시 처리

집필 흐름을 멈추지 않고 병행한다:
- **플롯 구멍·논리 모순 발견** → 챕터 완료 전이라도 **즉시** `docs/issues.md`에 등급과 함께 기록 후 집필 계속

## 집필 완료 체크리스트

원고 작성 직후, 문서 처리 전에 아래 체크리스트를 평가하고 결과를 화면에 출력한다.

각 항목은 ✅ (충족) / ⚠️ (부분 충족) / ❌ (미충족) 중 하나로 표시하고, ⚠️·❌ 항목에는 한 줄 코멘트를 붙인다.

출력 형식:

```
## 집필 체크리스트 — {챕터명}

### 📋 플랜 충실도
✅/⚠️/❌ 씬 순서        — {계획된 씬이 순서대로 포함되었는지}
✅/⚠️/❌ 씬 분량 배분   — {계획서의 씬 비중과 실제 분량이 크게 어긋나지 않는지}
✅/⚠️/❌ 감정선         — {계획된 감정 흐름을 따르는지}
✅/⚠️/❌ 복선 포인트    — {계획서에 명시된 복선이 심어졌는지}
✅/⚠️/❌ 챕터 엔딩      — {계획된 훅·여운·전환점으로 마무리됐는지}

### 🖊️ 문체
✅/⚠️/❌ 문장 리듬      — {스타일 프로필의 문장 길이·배분 패턴을 따르는지}
✅/⚠️/❌ 어휘 경향      — {한자어·구어체 비율이 프로필과 일치하는지}
✅/⚠️/❌ 서술 거리      — {프로필의 시점 거리를 유지하는지}
✅/⚠️/❌ 감정 표현 방식 — {직접 서술 vs 간접 표현 비율이 프로필에 맞는지}

### 👤 인물·설정
✅/⚠️/❌ 인물 설정 일관성 — {캐릭터 배경·능력·관계가 설정과 충돌하지 않는지}
✅/⚠️/❌ 세계관 일관성   — {장소·규칙·사건이 세계관 설정과 맞는지}
✅/⚠️/❌ 시점 오염       — {시점 인물이 알 수 없는 정보가 서술되지 않았는지}
✅/⚠️/❌ 시간·공간 연속성 — {장면 전환 시 시간 흐름·위치가 자연스럽게 연결되는지}

### 💬 대사
✅/⚠️/❌ 말투 일관성    — {인물별 고유 말투를 유지하는지}
✅/⚠️/❌ 상황 적절성    — {대사가 해당 장면의 감정·긴장도에 맞는지}
✅/⚠️/❌ 정보 자연성    — {설명적 대사(as-you-know) 없이 자연스러운지}

### ✍️ 산문 품질
✅/⚠️/❌ 감각 다양성    — {시각 외 청각·촉각·후각·미각 등 다른 감각이 활용됐는지}
✅/⚠️/❌ 설명 과잉      — {"~했다. 왜냐하면" 식의 작가 개입 없이 보여주기로 처리됐는지}
```

- 스타일 프로필이 없으면 문체 섹션 전체를 `—` 로 표시하고 "(스타일 프로필 없음)" 을 명시한다
- 계획서가 없으면 플랜 충실도 섹션 전체를 `—` 로 표시하고 "(계획서 없음)" 을 명시한다
- ❌ 항목이 있을 경우 체크리스트 하단에 **"위 항목을 수정할까요?"** 를 출력한다

## 집필 후 처리

위 체크리스트 출력 후 자동으로 수행한다. 문서 형식은 `docs/characters/_template.md`, `docs/events/_template.md` 참조:
- 새 인물 등장 → `docs/characters/{이름}.md` 생성
- 새 장소·공간 등장 → `docs/world/setting.md` 추가
- 새 사건·규칙 확정 → `docs/events/{사건명}.md` 생성
- `src/TOC.md` 상태를 `초고 완료`로 갱신
- `docs/synopsis.md` 업데이트 (챕터 내용 반영)
- `docs/TODO.md` 관련 항목 `- [x]` 체크
- `docs/overview.md` 갱신
