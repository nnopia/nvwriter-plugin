# 설정 문서 작성 스킬

설정 문서는 소설에 반영하기로 결정한 요소를 설계·기록하는 공간입니다.
`docs/idea/`(미결)와 달리, 이 문서들은 쓰기로 확정된 요소만 담습니다.

## 시작 전 구조 확인

`docs/` 폴더가 존재하는지 확인한다. 없으면 아래 메시지를 출력하고 중단한다:

> "프로젝트 구조가 없습니다. `/init`을 먼저 실행해 주세요."

---

## 캐릭터 문서 (`docs/characters/{이름}.md`)

```markdown
# {이름}

## 기본 정보
- **나이**: 
- **외모**: 

## 성격

## 말투 특징
<!-- 예: 격식체, 짧고 직설적인 문장, 감탄사 없음 -->
<!-- 예: 반말, 감정 표현 직접적, 비유 즐겨 씀 -->

## 관계
- {인물명}: 

## 캐릭터 아크
- 시작: 
- 변화: 
- 결말: <!-- 미확정이면 "미정" 으로 표시, 알려진 방향만 기록해도 됨 -->

## 등장 챕터
```

## 세계관 문서

### `docs/world/setting.md` — 공간·시간·분위기

장소가 추가될 때마다 아래 형식으로 항목을 추가합니다:

```markdown
## {장소명}
- **시대·분위기**: 
- **묘사**: 
- **관련 사건·인물**: 
```

### `docs/world/rules.md` — 사회 구조·특수 설정

반복 등장하는 규칙·문화·마법체계 등을 항목으로 추가합니다:

```markdown
## {규칙명}
- **설명**: 
- **소설에서의 역할**: 
```

## 사건 문서 (`docs/events/{사건명}.md`)

```markdown
# {사건명}

- **시점**: 
- **장소**: 
- **내용**: 
- **인과관계**: 왜 일어났는가 / 결과
- **영향**: 등장인물에게 미치는 영향
```

## 작성 시점

- **설계 시**: 대화·지시로 요소가 구체화될 때 즉시 작성합니다.
- **집필 후**: 챕터에 새 인물·장소·사건이 등장하면 챕터 완료 직후 즉시 작성합니다. 별도 지시 없이 자동으로 수행합니다.
