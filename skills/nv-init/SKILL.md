# 프로젝트 초기화

새 소설 프로젝트를 설정합니다. 아래 순서대로 실행합니다.

---

## Step 1 — 기존 구조 확인

`docs/`, `src/` 폴더 존재 여부를 확인한다.
이미 존재하면 사용자에게 알리고 중단한다. (덮어쓰지 않는다)

---

## Step 2 — 소설 기본 정보 수집

아래 항목을 사용자에게 묻는다. 모두 선택사항이며 나중에 채워도 된다:
- 소설 제목
- 장르 / 분위기

수집한 값을 이후 Step 4의 파일 생성 시 반영한다. 답하지 않은 항목은 `_작성 전_`으로 유지한다.

---

## Step 3 — 디렉터리 생성

```

```

---

## nvwriter 워크플로우

이 프로젝트는 nvwriter 플러그인을 사용합니다.

| 단계 | 커맨드 | 역할 |
|------|--------|------|
| 아이디어 | /nv-bs | 브레인스토밍 |
| 설정 문서 | /nv-wiki | 캐릭터·세계관·사건 문서 작성 |
| 챕터 설계 | /nv-plan | 씬·감정선·복선 설계 |
| 집필 | /nv-write | 원고 집필 |
| 문체 | /nv-style | 문체 분석·적용 |
| 검토 | /nv-review | 품질 검토 및 A/B/C 판정 |
| 수정 | /nv-revise | 검토 주석 기반 수정 |

## 네비게이션 원칙

파일이나 설정을 찾을 때는 항상 `docs/overview.md`를 먼저 확인한다.
챕터 진행 상태는 `src/TOC.md`를 기준으로 한다.

## 설정 동기화 원칙

챕터가 검토 완료 상태가 되면, 해당 챕터에서 확정된 정보를 관련 설정 문서에 역방향 동기화한다:
- 기존 인물의 새 성격·말투·관계 변화 → `docs/characters/{이름}.md` 갱신
- 기존 인물의 캐릭터 아크 진행 → `docs/characters/{이름}.md` 아크 항목 갱신
- 기존 장소·세계관에 새로 확정된 디테일 → `docs/world/setting.md` 또는 `docs/world/rules.md` 갱신
- 기존 사건의 결말·영향이 확정됨 → `docs/events/{사건명}.md` 갱신

## Step 6 — 기존 자료 임포트

사용자에게 묻는다:
> "소설에 대해 이미 구상한 자료가 있나요? (캐릭터 설명, 세계관, 플롯 메모 등)
> 있다면 텍스트로 붙여넣거나 파일 경로를 알려주세요."

자료가 있으면 내용을 분석해 적절한 문서로 저장한다:
- 인물 정보 → `docs/characters/{이름}.md` (`docs/characters/_template.md` 양식 사용)
- 세계관·장소 정보 → `docs/world/setting.md` 또는 `docs/world/rules.md`
- 사건 정보 → `docs/events/{사건명}.md` (`docs/events/_template.md` 양식 사용)
- 줄거리·플롯 → `docs/synopsis.md`
- 아직 미확정인 아이디어 → `docs/idea/` (`docs/idea/_template.md` 양식 사용)

자료가 없으면 이 단계를 건너뛴다.

---

## Step 7 — 완료 보고

초기화가 완료되면 아래 내용을 사용자에게 보고한다:
- 생성된 디렉터리·파일 목록
- 임포트된 자료 요약 (있는 경우)
- 다음 권장 작업 (`/nv-bs`로 아이디어 구상 또는 `docs/synopsis.md` 작성 시작)
- 선택 안내: 특정 문체로 집필하고 싶다면 `/nv-style`로 기본 문체를 설정할 수 있다 (나중에 해도 됨)
