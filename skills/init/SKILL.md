# 프로젝트 초기화

새 소설 프로젝트를 설정합니다. 아래 순서대로 실행합니다.

---

## Step 1 — 기존 구조 확인

`docs/`, `src/` 폴더 존재 여부를 확인한다.
이미 존재하면 사용자에게 알리고 중단한다. (덮어쓰지 않는다)

---

## Step 2 — 소설 기본 정보 수집

아래 항목을 사용자에게 묻는다. 모두 선택사항이며 나중에 채워도 된다:
- 소설 제목
- 장르 / 분위기

---

## Step 3 — 디렉터리 생성

```
src/
docs/
docs/idea/character/
docs/idea/setting/
docs/idea/story/
docs/idea/theme/
docs/characters/
docs/world/
docs/events/
docs/plans/
```

---

## Step 4 — 포맷 파일 생성

아래 파일들을 생성한다. 이미 존재하는 파일은 건너뛴다.

| 챕터 | 제목 | 상태 | 비고 |
|------|------|------|------|
| ch01 | | 미집필 | |

### `docs/TODO.md`

### `docs/issues.md`
```markdown
# Issues — 미결 과제

설정 미확정, 플롯 구멍, 논리적 모순 등 해결이 필요한 문제를 기록합니다.

## 등급 기준

| 등급 | 의미 | 집필 가능 여부 |
|------|------|---------------|
| 🔴 blocker | 이 문제가 해결되지 않으면 해당 챕터 집필 불가 | 반드시 먼저 해결 |
| 🟡 normal | 집필은 가능하지만 다음 챕터 전까지 해결 필요 | 집필 후 해결 |
| 🟢 deferred | 나중에 해결해도 무방 | 자유 |

---

## 🔴 Blocker

_없음_

## 🟡 Normal

_없음_

## 🟢 Deferred

_없음_

---

## 해결 완료

_없음_
```

## Step 5 — CLAUDE.md 업데이트

`CLAUDE.md`가 없으면 생성, 있으면 `## 일반 원칙` 섹션에 아래 트리거 규칙을 추가한다.
이미 동일한 내용이 있으면 건너뛴다.

```
- **프로젝트 초기화 요청 시** `.claude/commands/init.md`를 읽고 따릅니다.
- **챕터 계획 요청 시** 작업 전에 `.claude/commands/plan.md`를 읽고 따릅니다.
- **집필 요청 시** 작업 전에 `.claude/commands/write.md`를 읽고 따릅니다.
- **검토 요청 시** 작업 전에 `.claude/commands/review.md`를 읽고 따릅니다.
- **수정 요청 시** 작업 전에 `.claude/commands/revise.md`를 읽고 따릅니다.
- **브레인스토밍 요청 시** 작업 전에 `.claude/commands/bs.md`를 읽고 따릅니다.
- **설정 문서 작성 요청 시** 작업 전에 `.claude/commands/wiki.md`를 읽고 따릅니다.
- **문체 분석·적용 요청 시** 작업 전에 `.claude/commands/style.md`를 읽고 따릅니다.
```

`## 프로젝트 설정` 섹션도 추가한다:

```
## 프로젝트 설정

<!-- 아래 항목을 프로젝트에 맞게 수정하세요 -->

수정 주석 형식: <!-- -->
```

## Step 6 — 기존 자료 임포트

사용자에게 묻는다:
> "소설에 대해 이미 구상한 자료가 있나요? (캐릭터 설명, 세계관, 플롯 메모 등)
> 있다면 텍스트로 붙여넣거나 파일 경로를 알려주세요."

자료가 있으면 `.claude/commands/wiki.md`를 읽고 내용을 분석해 적절한 문서로 저장한다:
- 인물 정보 → `docs/characters/{이름}.md`
- 세계관·장소 정보 → `docs/world/setting.md` 또는 `docs/world/rules.md`
- 사건 정보 → `docs/events/{사건명}.md`
- 줄거리·플롯 → `docs/synopsis.md`
- 아직 미확정인 아이디어 → `docs/idea/` (bs.md 절차에 따라)

자료가 없으면 이 단계를 건너뛴다.

---

## Step 7 — 완료 보고

초기화가 완료되면 아래 내용을 사용자에게 보고한다:
- 생성된 디렉터리·파일 목록
- 임포트된 자료 요약 (있는 경우)
- 다음 권장 작업 (`/bs`로 아이디어 구상 또는 `docs/synopsis.md` 작성 시작)
- 선택 안내: 특정 문체로 집필하고 싶다면 `/style`로 기본 문체를 설정할 수 있다 (나중에 해도 됨)
