# 챕터 검토 기준

## 시작 전 구조 확인

`docs/`와 `src/` 폴더가 존재하는지 확인한다. 없으면 아래 메시지를 출력하고 중단한다:

> "프로젝트 구조가 없습니다. `/init`을 먼저 실행해 주세요."

---

## 검토 대상 특정

- 사용자가 파일을 직접 지정하면 해당 파일을 검토한다
- 지정이 없으면 `src/TOC.md`를 읽어 가장 최근 `초고 완료` 상태인 챕터를 검토 대상으로 삼고 사용자에게 확인한다

## 검토 전 참조

- `docs/plans/plan_ch{번호}.md`가 존재하면 읽어 검토 기준으로 삼는다. 없으면 계획서 없이 진행한다.

## 검토 축

### 1. 문장
- 어색한 표현·문법 오류가 없는가
- 문장 리듬감이 장면의 흐름과 맞는가

### 2. 감정·묘사
- 인물의 감정이 독자에게 전달되는가
- 장면 묘사가 구체적이고 생생한가

### 3. 구조
- 씬 순서가 논리적인가
- 인물 행동에 개연성이 있는가
- 복선이 적절히 설치되거나 회수됐는가

### 3-1. 계획서 대조 (계획서가 있는 경우)
- 씬 목록의 순서·목적이 계획서와 일치하는가
- 감정선(시작·전환점·끝)이 계획서 설계대로 흘러가는가
- 계획서에 명시된 복선 설치·회수가 실제로 반영됐는가
- 계획서의 묘사 포인트가 충분히 구현됐는가
- 계획서와 크게 다르면 의도적 변경인지 사용자에게 확인한다

### 4. 일관성
- 캐릭터 말투·성격·외모·관계가 `docs/characters/{이름}.md`와 일치하는가 — 해당 챕터에 등장하는 인물의 파일만 열어 비교한다
- 캐릭터 특성이 이전 챕터 대비 이유 없이 변하지 않았는가
- 챕터에 등장하는 장소·사건이 있으면 관련 `docs/world/setting.md` 항목 및 `docs/events/{사건명}.md`만 열어 설정 충돌을 확인한다

### 5. 문체
- `.claude/styles/default.md`가 존재하면 해당 스타일 프로필을 읽고 아래 항목을 대조한다:
  - 문장 리듬(평균 길이, 짧은/긴 문장 배분)이 프로필과 일치하는가
  - 어휘 경향(한자어·구어체 비율 등)이 일관되게 유지되는가
  - 서술 거리와 감정 표현 방식이 프로필 기준과 맞는가
- `.claude/styles/default.md`가 없으면 챕터 내 문체 내부 일관성만 확인한다:
  - 전반부와 후반부 사이 문체가 이유 없이 달라지지 않았는가
  - 화자 시점이나 서술 거리가 씬 중간에 흔들리지 않는가

### 6. 간결성 (덜어내기)
- **문장 단위:** 스토리 흐름에 기여하지 않는 문장이 있는가 — 없애도 서사가 끊기지 않는다면 제거 대상이다
  - 이미 앞 문장에서 전달한 정보를 반복하는 문장
  - 감정·분위기를 설명하지만 행동·대화로 이미 드러난 내용의 중복
  - 독자의 이해에 필요 없는 부연 설명
- **단어 단위:** 문장 안에 의미 없이 들어간 단어가 있는가
  - 뺐을 때 의미가 달라지지 않는 수식어·부사
  - 같은 의미를 두 번 표현하는 동의어 병렬 ("크고 거대한", "작고 아담한" 류)
  - 문장을 길게 늘이기만 하는 접속 표현

## 검토 보고 형식

1. **강점** — 잘 된 부분
2. **개선 필요** — 문제 항목과 구체적 위치
3. **권고사항** — 수정 방향 제안

---

## 검토 결과 처리

### A. 통과
- `src/TOC.md` 해당 챕터 상태를 `검토 완료`로 갱신한다
- `docs/synopsis.md`를 업데이트한다
- `docs/overview.md`의 파일별 요약에서 해당 챕터 상태를 갱신한다
- 챕터에서 확정된 정보를 기존 설정 문서에 역방향 동기화한다 (CLAUDE.md `## 설정 동기화 원칙` 참조)

### B. 일부 수정 / C. 구조 문제
문제가 있는 위치에 챕터 파일 내 주석으로 기록한 뒤 `/revise`로 처리한다.

**주석 형식:**
```
<!-- [B] 문제 내용 → -->
<!-- [C] 문제 내용 → -->
```

- 문제가 발생한 문장·문단 바로 위에 삽입한다
- 챕터 전체에 걸친 구조 문제(C)는 파일 상단에 기록한다
- `src/TOC.md`의 해당 챕터 상태를 `초고 완료`로 유지한다 (주석이 남아있는 한 `검토 완료`로 올리지 않는다)
- `→ ` 뒤는 사용자가 수정 방향을 직접 덧붙일 수 있도록 비워둔다. 사용자가 채우지 않으면 revise가 자체 판단으로 수정한다.

## A/B/C 판단 기준

| 증상 | 경로 |
|------|------|
| 문장·표현이 어색하다 | B |
| 감정 묘사가 약하다 | B |
| 문체가 스타일 프로필과 불일치한다 | B |
| 챕터 내 문체 일관성이 흔들린다 | B |
| 서사에 기여하지 않는 불필요한 문장이 있다 | B |
| 문장 내 의미 없는 단어·반복 표현이 있다 | B |
| 씬 순서가 이상하다 | C |
| 인물 행동에 납득이 안 된다 | C |
| 복선이 누락됐다 | C |
| 설정 문서와 충돌한다 | C |
