# 문체 스킬

특정 작가나 텍스트의 문체를 분석하고, 저장된 스타일 프로필을 집필에 적용합니다.

---

## 시작 전 구조 확인

`docs/` 폴더가 존재하는지 확인한다. 없으면 아래 메시지를 출력하고 중단한다:

> "프로젝트 구조가 없습니다. `/init`을 먼저 실행해 주세요."

---

## 모드 판단

요청을 받으면 먼저 아래 기준으로 모드를 결정한다:

| 요청 패턴 | 모드 |
|-----------|------|
| "문체 분석해줘", "이 작가 스타일 파악해줘", 샘플 텍스트 제공 | 분석 모드 |
| "이 스타일로 써줘", "저장된 {스타일명} 적용해줘" | 적용 모드 |
| 둘 다 해당하거나 불명확 | 사용자에게 확인 |

---

## 분석 모드

샘플 텍스트 또는 작가명이 주어지면 아래 항목을 추출한다.

> **주의**: 작가명만 제공된 경우 학습 데이터 기반 추정이므로 정확도를 보장할 수 없다. 분석 결과를 사용자에게 보여주고 검토·수정을 요청한 뒤 저장한다. 샘플 텍스트가 있으면 정확도가 높아지므로 가능하면 제공을 권장한다.

- **문장 리듬**: 평균 문장 길이, 짧은 문장과 긴 문장의 배분 패턴
- **어휘**: 한자어·순우리말 비율, 구어체·문어체 경향, 자주 쓰는 표현 패턴
- **서술 거리**: 인물 내면에 밀착하는가 / 관찰자 시점으로 거리를 두는가
- **감정 표현**: 직접 서술("슬펐다") vs 간접 표현(행동·감각으로 암시)
- **묘사 밀도**: 장면 묘사의 세밀함, 감각 정보 활용 방식
- **대화 처리**: 대화 비중, 지문 스타일, 대화 내 인물 개성 표현 방식

분석이 완료되면 `.claude/styles/{스타일명}.md`에 프로필을 저장합니다.

기본 문체로 지정하려면 동일한 내용을 `.claude/styles/default.md`로 저장하거나, 기존 파일을 `default.md`로 복사한다. `default.md`가 있으면 집필 시 자동으로 적용된다.

---

## 저장 형식 (`.claude/styles/{스타일명}.md`)

```markdown
# {스타일명} 문체 프로필

## 출처
- 작가 / 작품명 또는 샘플 텍스트 요약

## 문장 리듬
## 어휘
## 서술 거리
## 감정 표현
## 묘사 밀도
## 대화 처리

## 적용 시 주의사항
```

---

## 적용 모드

집필 시 특정 스타일을 적용하라는 요청이 오면:

1. `.claude/styles/` 에서 해당 프로필 파일을 읽는다
2. 프로필의 각 항목을 집필에 반영한다
3. `.claude/commands/write.md`의 산문 원칙과 충돌할 경우 스타일 프로필을 우선한다
