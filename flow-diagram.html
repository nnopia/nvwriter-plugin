소설 집필 워크플로우

아이디어 발산부터 탈고까지 — 6단계 집필 프로세스 가이드

P1
Phase 1
아이디어 발산
쓸지 말지 결정하지 않아도 됩니다. 떠오른 것을 자유롭게 꺼내는 단계입니다.
충분히 구체화되면 타입에 맞는 문서로 반영합니다.
명령어 /bs
저장 위치 docs/idea/{타입}/
상태 흐름 구상 중 → 검토 가능 → 반영 완료
타입 반영 시 목적지 다음 단계
character docs/characters/ /wiki
setting docs/world/ /wiki
story docs/TODO.md /plan
theme docs/synopsis.md —
P2
Phase 2
기획 확정
소설에 쓰기로 결정한 요소들을 설계하고 문서로 남깁니다.
인물·세계관·사건을 구체화하고, 전체 줄거리를 잡아갑니다.
명령어 /wiki
인물 docs/characters/{이름}.md
세계관 docs/world/setting.md · docs/world/rules.md
사건 docs/events/{사건명}.md
줄거리 docs/synopsis.md — 처음엔 한 줄 요약만 써도 됩니다
이슈 등록 미확정·모순·플롯 구멍은 docs/issues.md에 등급과 함께 기록합니다
🔴 blocker — 집필 불가  ·  🟡 normal — 다음 챕터 전까지  ·  🟢 deferred — 나중에
P3
Phase 3
챕터 설계
집필 전에 챕터를 씬 단위로 쪼개어 설계합니다.
건너뛰어도 집필할 수 있지만, 구조 문제를 미리 잡아 나중에 전면 재작업하는 상황을 줄입니다.
명령어 /plan
결과물 docs/plans/plan_ch{번호}.md
설계 항목 씬 목록 · 목적 · 시점 인물 · 감정선 · 복선 설치/회수 · 묘사 포인트
주의 🔴 blocker 이슈가 있으면 먼저 해결 후 진행합니다
P4
Phase 4
집필
계획서를 바탕으로 원고를 씁니다.
새로 등장한 인물·장소·사건은 집필 직후 자동으로 설정 문서에 추가됩니다.
명령어 /write  ·  /style (문체 적용)
원고 위치 src/part{N}_{파트제목}/ch{N}_{챕터제목}.md
기본 문체 .claude/styles/default.md 가 있으면 자동 적용

초고 완료
집필 후 characters · world · events 자동 갱신 · synopsis.md 업데이트 · TODO 완료 체크
P5
Phase 5
검토
완성된 챕터를 문장·감정·구조·일관성 4가지 축으로 점검합니다.
결과에 따라 세 가지 경로로 분기합니다.
명령어 /review
검토 축 문장 리듬 · 감정 묘사 · 씬 구조 · 설정 일관성
검토 결과 분기
A
통과 — 전체적으로 문제 없음
→ TOC 상태 검토 완료로 갱신 · synopsis.md 업데이트
B
일부 수정 — 문장·표현·감정 묘사 수준의 문제
→ 원고에 <!-- [B] 내용 --> 주석 삽입 후 /revise 처리
C
구조 문제 — 씬 순서·인물 동기·복선·설정 충돌
→ 원고에 <!-- [C] 내용 --> 주석 삽입 후 /revise 처리
B 증상 문장·표현이 어색하다 · 감정 묘사가 약하다
C 증상 씬 순서가 이상하다 · 인물 행동에 납득이 안 된다 · 복선이 누락됐다 · 설정 문서와 충돌한다
P6
Phase 6
수정
검토에서 삽입된 주석을 하나씩 처리합니다.
[C] 주석 먼저, [B] 주석 나중 순서로 진행합니다.
명령어 /revise
처리 순서 [C] 구조 문제 먼저 → [B] 문장 수정 나중
B 처리 해당 문장·문단 직접 수정 후 주석 제거
C 처리 계획서(docs/plans/) 재설계 → 원고 재집필 → 집필 후 처리 동일 수행
완료 시 모든 주석 제거 → 사용자 확인 → TOC 검토 완료 · synopsis.md 업데이트

· 미집필 → 집필 중  : 집필 시작 시 (blocker 없음 확인 후)
· 집필 중 → 초고 완료  : 챕터 원고 완성 시
· 초고 완료 → 검토 완료  : A 통과 또는 /revise 전체 완료 후 승인 시
· B/C 판정 시 주석이 남아있는 동안은 초고 완료 상태를 유지합니다
