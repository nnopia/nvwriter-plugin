# 집필 스킬

## 시작 전 구조 확인

`docs/`와 `src/` 폴더가 존재하는지 확인한다. 없으면 아래 메시지를 출력하고 중단한다:

> "프로젝트 구조가 없습니다. `/init`을 먼저 실행해 주세요."

---

## 집필 전 준비

챕터를 쓰기 전 반드시 읽는다:
1. `docs/plans/plan_ch{번호}.md` — 씬 순서·감정선·복선 포인트 확인
   - 계획서가 없으면 집필 전에 사용자에게 계획서 작성을 먼저 제안한다. 사용자가 계획서 없이 진행을 원하면 그대로 따른다.
2. 해당 챕터 등장 인물의 `docs/characters/{이름}.md` — 말투·성격·관계 확인
3. 필요 시 `docs/world/setting.md`, 관련 `docs/events/` 문서
4. `.claude/styles/` — 스타일 프로필 확인:
   - 사용자가 특정 스타일을 지정했으면 해당 파일을 읽는다
   - 지정이 없으면 `.claude/styles/default.md`가 있는지 확인하고, 있으면 자동으로 적용한다

준비가 끝나면 `src/TOC.md` 해당 챕터 상태를 확인하고 아래 기준으로 갱신한다:
- `미집필` 상태면 `집필 중`으로 갱신한다
- `집필 중` 또는 `초고 완료` 상태면 그대로 유지한다 (이어쓰기 시 상태를 되돌리지 않는다)

**이어쓰기 요청 시** 위 준비에 추가로:
- 이전 챕터 파일의 마지막 장면(최소 마지막 500자)을 읽어 문체·감정선·상황을 이어받는다

## 산문 원칙

- **보여주기**: 감정과 상태를 직접 서술하지 않고 행동·감각·대화로 드러낸다
- **리듬**: 긴장 장면은 짧은 문장, 여운 장면은 긴 문장으로 호흡을 조절한다
- **감각**: 시각 외에 청각·촉각·후각·미각을 적절히 활용한다
- **구체성**: 추상적 표현보다 구체적 디테일로 장면을 살린다

## 시점

- 챕터 내 시점(1인칭 / 3인칭 제한)을 일관되게 유지한다
- 시점 인물이 알 수 없는 정보는 서술하지 않는다

## 대화

- 인물마다 고유한 말투를 유지한다 (`docs/characters/`의 말투 항목 참조)
- 대화는 정보 전달과 감정 표현을 동시에 한다
- 설명적 대화(as-you-know dialogue)를 피한다

## 집필 중 — 즉시 처리

집필 흐름을 멈추지 않고 병행한다:
- **플롯 구멍·논리 모순 발견** → 챕터 완료 전이라도 **즉시** `docs/issues.md`에 등급과 함께 기록 후 집필 계속

## 집필 후 처리

챕터 완료 직후 자동으로 수행한다. 문서 형식은 `.claude/commands/wiki.md` 참조:
- 새 인물 등장 → `docs/characters/{이름}.md` 생성
- 새 장소·공간 등장 → `docs/world/setting.md` 추가
- 새 사건·규칙 확정 → `docs/events/{사건명}.md` 생성
- `src/TOC.md` 상태를 `초고 완료`로 갱신
- `docs/synopsis.md` 업데이트 (챕터 내용 반영)
- `docs/TODO.md` 관련 항목 `- [x]` 체크
- `docs/overview.md` 갱신
